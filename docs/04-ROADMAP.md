## 4. 关键决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| LLM 客户端 | OpenAI 兼容协议 | 可切换 DeepSeek / 中科大 / 其他平台 |
| 数据库 | PostgreSQL (非 SQLite) | 支持 FTS、远程访问、并发写入 |
| 前端框架 | React + shadcn/ui | 组件丰富、主题可定制、生态成熟 |
| 构建工具 | Vite | 开发体验好，构建快 |
| HTTP 框架 | Echo v4 | 轻量、性能好、中间件丰富 |
| 日志 | `log/slog` (stdlib) | Go 1.21+ 标准库，无需外部依赖 |
| 部署 | GitHub Actions | 零成本、与代码仓库集成 |
| 配置 | 环境变量 | 12-Factor App 最佳实践 |
| 会话存储 | 内存 (Phase 1) → DB (Phase 2) | MVP 快速迭代，后续持久化 |
